KLG BLOCK 1.1 — ATUALIZAÇÃO DO PROJETO ANDROID

Este ZIP contém o projeto para o GitHub Actions gerar o APK; não é um APK pronto.

NOVIDADES
- Novo mascote Calango e logo KLG nas telas, ícones e abertura.
- Mascote comemora quando o jogador completa linhas ou combina combos.
- Partículas e brilho no tabuleiro durante as comemorações.
- Melodia extra para combos grandes.

PRESERVADO DO KLG BLOCK 1.0
- Tabuleiro 8x8, três peças, arrastar e soltar e toque para encaixar.
- Pontuação, recorde, XP, moedas e salvamento local.
- Mesmo identificador Android: br.com.klg.block.
- Mesma chave de armazenamento WebView: klg-block-v1.0.
- Funciona totalmente offline.

COMO ATUALIZAR NO GITHUB
1. Antes de mexer, salve o APK 1.0 e crie uma tag ou baixe um ZIP de backup
   do repositório atual.
2. Extraia este ZIP no computador.
3. No repositório GitHub, envie os arquivos substituindo os antigos.
   Confira se há app/, .github/workflows/, index.html, app.js, style.css,
   logo-klg.png e icon-192.png/icon-512.png nas pastas certas.
   Em caso de uso da interface web, para sobrescrever e manter pastas,
   é mais confiável editar arquivos existentes ou usar github.dev.
4. Abra Ações / Actions > Gerar APK KLG Block > última execução verde.
5. Em Artifacts, baixe KLG_Block_1.1_APK, extraia o KLG_Block_1.1.apk.

ATENÇÃO IMPORTANTE SOBRE INSTALAÇÃO
- APKs debug gerados em diferentes execuções do GitHub podem ser assinados
  por chaves diferentes. Mesmo tendo versionCode maior, o Android pode
  RECUSAR a instalação por cima do APK 1.0.
- NÃO desinstale o APK 1.0 antes de avaliar se aceita perder o progresso;
  desinstalar pode apagar recordes, moedas, XP e a partida salva.
- A solução permanente é configurar uma chave de assinatura estável para
  versões futuras, ou instalar uma versão separada para teste.
- Não testamos esta compilação em um aparelho físico nesta sessão.
