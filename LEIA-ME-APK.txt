KLG BLOCK 1.2 — CORREÇÃO DE PROGRESSO + MISSÕES DIÁRIAS

Este pacote contém os arquivos do projeto Android para compilar no GitHub.
Ele NAO é um APK pronto.

PRINCIPAIS MUDANÇAS
- Preserva tabuleiro 8x8, arraste, combos, sons, logo e Calango animado.
- Separa recorde, moedas e XP dos dados da partida, e guarda backup local redundante.
- Reaproveita o armazenamento v1.0/v1.1 quando o aplicativo é atualizado POR CIMA.
- Botão SALVAR / RECUPERAR PROGRESSO na tela inicial: copie o código KLG-
  para guardar recorde, moedas e XP antes de reinstalar (nao inclui partida
  em andamento ou missões).
- 3 missões diárias: 5 linhas, 2 combos x2+, 20 peças. Resgate manual de
  recompensas, uma vez por missão/dia. Reiniciam ao mudar a data local.
- Preserva funcionamento offline; nenhuma conta ou internet necessárias.

ATUALIZAÇÃO NO GITHUB
1. Primeiro faça backup da versão 1.1 (GitHub > Code > Download ZIP).
2. Extraia o pacote de atualização.
3. Mantenha as pastas e a estrutura: app/build.gradle,
   .github/workflows/gerar-apk.yml e arquivos web na raiz.
4. Substitua os 8 arquivos do ZIP no repositório existente.
   Se o upload do GitHub não sobrescrever corretamente, use o editor do
   GitHub para alterar o arquivo existente ou github.dev.
5. Entre em GitHub > Actions (Ações) > Gerar APK KLG Block.
6. Após a execução verde, abra Artifacts > KLG_Block_1.2_APK,
   extraia o arquivo KLG_Block_1.2.apk e instale no Android.

ATENÇÃO — PRESERVAR PROGRESSO
- O mesmo applicationId br.com.klg.block foi mantido (versionCode 3).
- APK debug compilado pelo GitHub pode usar uma chave diferente da versão
  instalada. Nesse caso, o Android não permite a atualização por cima.
- Se aparecer erro de assinatura, PARE: NÃO desinstale a versão anterior.
  A versão 1.1 não tinha gerador de código de backup e a desinstalação
  pode apagar recordes, moedas, XP e partida salva.
- Este pacote não resolve sozinho uma diferença de assinatura entre APKs.
- Para atualizações permanentes, é preciso usar uma chave de assinatura
  estável guardada fora de repositórios públicos.
- O teste de lógica JS passou. A compilação APK e o teste no Android real
  dependem da execução do GitHub e do dispositivo.
